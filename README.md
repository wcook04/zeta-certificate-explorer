# Zeta certificate explorer

Browse the certified zero intervals from Salvatore Mercuri and Bhavik Mehta’s
[Lean verification up to height 10,011](https://github.com/smmercuri/zeta/tree/34037d5a7662e2eb6e970bfb22299c84e45ed5d9).
The explorer shows the exact endpoints, the certified signs of Hardy’s Z
function, and the error bounds used to prove those signs.

- [Open the explorer](https://wcook04.github.io/zeta-certificate-explorer/) or start with [certificate 2391](https://wcook04.github.io/zeta-certificate-explorer/#/2391).
- [Browse the catalogue files](downloads/) for the interval CSV, full certificates CSV, JSON, provenance and evidence archive.
- [Read the working paper](https://github.com/wcook04/zeta-certificate-explorer/blob/gh-pages/papers/riemann-siegel-lehmer-pair-20261124.pdf) on shared Riemann–Siegel bounds and the Lehmer pair.
- [View the source and hosting instructions](https://github.com/wcook04/zeta-certificate-explorer/blob/main/README.md#build-and-host).

This branch contains the static files served by GitHub Pages. The
[main repository README](https://github.com/wcook04/zeta-certificate-explorer/blob/main/README.md)
explains the catalogue, its extraction, and how to rebuild the explorer.
